# Castiel 完整工作台设计原型

个人工作与团队 PL 管理的本地浏览器交互原型，覆盖 Agent 极简首页、会话、今日、任务执行台、团队、方法论、扩展和设置。保留任务执行台结构和统一 Agent/模型入口；2026-10-24 已统一放大字体、重整页面宽度与留白，并完善灰蓝主题。视觉规范见上级目录 `视觉规范.md`。

## 体验路径

- 今日：自然语言演示拆解 → 修改计划 → 模拟并行执行 → 待验收。
- 项目一级入口暂缓；原有管理模块保留，Agent 工作空间不关联项目。
- 团队：成员资料、周容量、全部项目负载 → 调整预览 → 应用与撤销。
- Agent：首页大输入框，底部工具/模型/空间；每个工具独立的开始、设置、工作空间、模型页面。默认值只影响新会话。
- 快捷提示词：Agent 输入框下方四张卡片，一键填入、保留原稿追加、撤销填充，编辑后手动发送。
- 会话：独立一级菜单，搜索、工具/空间筛选、继续、重命名、归档和恢复；归档不取消任务。
- 方法论：来源、场景规则、候选文本、反例检查、模拟激活与回滚。
- 扩展：提出能力、检查候选、启用/停用与权限说明。
- 设置：浅深/系统主题、演示权限、通知、本地快照真实导出、更新流程预览。

## 运行与检查

统一的根目录开发命令与仓库说明见 [根目录 README](../README.md)。以下命令在 `prototype/` 内执行。

```sh
npm install
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
npm run build
node --test tests/agent-data.test.mjs tests/workspace-data.test.mjs
```

浏览器原型使用 React/Vite，不代表已确定桌面应用的软件选型。

## 数据与能力边界

任务、项目、成员和配置在当前页面共享，刷新后恢复虚构示例。仅主题偏好持久化于当前本机浏览器。导出按钮真实下载本地 JSON 快照；未实现导入生产数据库或恢复机制。

自然语言拆解、Agent 回复、规则检查、扩展启用及发布阶段均为明确标注的演示，不连接模型、不执行工具命令、不部署。附件入口只显示文件名；规则文本导入只在本机读取所选 .md/.txt。自定义工具配置不执行命令或连接地址，不读取密钥。

正式产品的后台执行、文件系统存储、模型后端、权限隔离、数据迁移、原生打包与更新均需后续实现。

详细设计位于上级目录的 `设计交付总览.md`、`工作台交互设计.md`、`关键页面交互规格.md`。视觉与浏览器检查见 `design-qa.md`，截图位于 `design/`。
