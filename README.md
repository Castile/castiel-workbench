# Castiel 工作台

代码仓库：[Castile/castiel-workbench](https://github.com/Castile/castiel-workbench)（私有）。当前桌面开发版：0.3.1。

面向个人工作与团队 PL 的本地桌面工作台。开发版采用 Electron + React，已接入真实本地保存、备份恢复和 macOS 打包；已接入本机 Codex 与 Claude Code 的配置探测和真实会话；每日自动编排、规则行为回归、扩展执行与发布仍为演示或待接入。

## 开发入口

验证环境：macOS Apple Silicon、Node.js 24.12.0、npm 11.6.2；Node 版本见 `.node-version`。在仓库根目录运行：

```sh
npm run setup             # 按锁文件安装依赖
npm run dev:desktop       # 构建并打开桌面开发版
npm run desktop:package   # 生成当前系统/架构的应用到 release/
npm run check             # 构建、业务与本地存储测试、静态产物检查
npm run dev               # 浏览器演示 http://127.0.0.1:4173
```

首次启动或打包会下载 Electron 官方运行时，安装依赖会访问 npm。下载受限时可将匹配版本、平台、架构的官方 ZIP 放到本地目录，通过 `CASTIEL_ELECTRON_ZIP_DIR=/path/to/zips npm run desktop:package` 使用。桌面界面从应用包加载，无需运行网页服务器。

根目录脚本统一委托 `prototype/`，依赖与锁文件保留在那里。`npm run preview` 在本机 4174 端口预览网页构建。浏览器版本保留虚构示例，业务数据不持久化。

## 本机 Agent 自动接入

每次启动自动检测 Claude Code 与 Codex 的安装入口、认证存在状态和模型配置，不需要重新填写 API Key。macOS Finder 的 PATH 差异通过本机登录 Shell 环境与常见安装位置兼容；环境只在主进程内存中使用，不输出或持久化完整环境。

- Codex：使用本机 `codex app-server` 的私有标准输入输出连接，读取有效配置、登录状态和模型目录；支持流式输出、停止、保存后端 thread ID、重启继续及常见的单次工具授权/补充问题。
- Claude：使用现有 `claude -p`，读取本机配置和模型别名，以 stream-json 输出回复并保存 session ID；保留原工具的认证、服务地址与权限规则。当前无交互权限宿主，需要额外授权且 CLI 规则未允许的操作会显示阻塞，不会绕过权限。
- Agent 页面有配置来源、版本、真实模型选项和「重新检测」。自动补充已安装工具，不覆盖独立设置、停用状态或已有空间范围。默认工作空间未绑定时使用工作台自己的本地目录，不会默认进入整个主目录。
- 发送才发起推理；启动探测不发送聊天内容，也不会自动执行旧会话。配置存在不代表服务有可用额度或模型访问权限，真实失败会显示在会话中。

目前真实验证：Codex 已返回实际回复；本机 Claude 自定义服务返回 `402 Insufficient Balance`，需处理该服务账户后重试。工作台没有修改服务配置或凭据。详见 [接入实现](docs/agent-integration.md)。

## 对话体验

桌面 0.3.0 已优化对话体验：用户消息靠右、Agent 回复使用居中阅读列；支持 Markdown、表格、代码高亮与原文复制。补充问题采用可选择、可自行填写和返回修改的对话卡片；工具授权仍为单次确认。向上阅读历史时保持位置，可点击「回到最新」。各工具图标来自官方资源并保存在本地，见 [资源来源](docs/brand-assets.md)。

0.3.1 修复对话的工作空间设置：点击输入框下方的空间按钮，可从本机选择目录或使用已有空间，再应用到当前对话。同一目录复用已有空间；左侧「＋」在当前空间建立独立空白对话，发送第一条消息后才调用 Agent。更换当前对话目录会保留记录并重新建立工具会话，其他对话和草稿保持原样；执行中或已归档的对话需先停止或恢复后才能换目录。

## 本地数据

macOS 默认目录为 `~/Library/Application Support/CastielWorkbench/`，可在「设置 → 数据」查看实际绝对路径。工作数据保存为 `workbench.json`，上一版保留为 `.bak`；缓存也在该目录内。会话、输入草稿、主题、成员、Agent 配置与工作空间自动保存，右下角显示真实保存状态。支持手动导出和恢复版本化 JSON 备份；保存失败保留未保存提示并提供重试。

`CASTIEL_DATA_DIR=/absolute/path` 可隔离开发验证数据。JSON 目前为明文，未实现磁盘加密或密钥管理，请勿填写密钥。真实模型请求由本机工具按现有配置发起，允许调用云模型。认证留在原工具，不复制到工作台文档。

关闭窗口前会等待保存；macOS 默认保留应用进程，点击 Dock 可重开。关闭后台偏好或使用 Cmd+Q 会在保存后退出。有 Agent 执行时，关闭前需选择返回工作台或停止并保存；此版尚不支持关窗后继续执行，休眠后不承诺任务恢复。强退或掉电只能恢复最近完成的写入，重新打开会标记中断，可继续发送。

## 仓库结构

```text
prototype/
  desktop/           Electron 主进程、隔离预加载、本地存储
  src/state/         文档格式、保存控制器、任务与会话数据模型
  src/               已确认的前端界面与演示交互
  tests/             业务、本地保存与静态服务测试
  design/            设计参考与验证截图
  worker/            保留的可选静态托管适配
docs/desktop-architecture.md  桌面选型、数据协议和能力边界
开发计划.md            各阶段状态与完成标准
```

Agent 首页、独立工具设置、会话一级入口、快捷提示词、深浅主题沿用已确认设计。项目一级菜单暂缓，Agent 空间独立于项目；普通会话独立于任务和团队负载。

`node_modules/`、`dist/`、`release/`、缓存、日志、凭据和真实用户数据不提交。源代码托管在上述 GitHub 私有仓库；未配置安装包远程发布或自动更新。macOS 包为本机临时签名，尚未进行 Developer ID 签名与公证。
