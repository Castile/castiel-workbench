# Castiel 工作台

面向个人工作与团队 PL 的本地桌面工作台。当前仓库是已经确认的交互设计与前端原型开发基线，尚未接入真实 Agent、模型推理或桌面后台。

## 开发入口

当前验证环境为 Node.js 24.12.0、npm 11.6.2；Node 版本见 `.node-version`。在仓库根目录运行：

```sh
npm run setup       # 按 prototype/package-lock.json 安装依赖
npm run dev         # http://127.0.0.1:4173
npm run check       # 构建、业务逻辑测试、产物与静态服务测试
```

依赖已安装时可直接启动。单独检查可使用 `npm test`、`npm run build`；`npm run test:package` 需要先完成构建。`npm run preview` 在本机 4174 端口预览最近的构建。

根目录只提供开发命令，前端依赖与锁文件保留在 `prototype/`。安装依赖会访问 npm；运行原型不调用模型服务。所有服务启动命令默认绑定本机地址。

## 仓库结构

```text
prototype/
  src/               前端界面、演示数据与交互
  tests/             数据逻辑与静态服务测试
  design/            已确认的视觉参考、截图与对比证据
  design-qa.md       视觉与流程检查记录
  worker/            保留的可选静态托管适配
  scripts/           构建产物整理
设计交付总览.md        产品范围与能力边界
工作台交互设计.md      需求、研究与信息结构
关键页面交互规格.md    详细页面行为
视觉规范.md            当前字体、布局与主题基线
开发计划.md            实现顺序与完成标准
```

`node_modules/`、`dist/`、缓存、日志和本地环境配置不提交。设计截图作为设计证据保留在 Git 中。当前只初始化本地仓库，未配置远程地址或自动发布。

## 已确认的产品边界

- Agent 首页为大输入框，底部选择工具、模型和工作空间，配有快捷提示词卡片。
- 每个 Agent 有独立设置、工作空间与默认模型；会话是单独的一级菜单。
- 项目一级入口暂缓，Agent 工作空间不关联项目；团队任务与人员负载另行管理。
- 数据与缓存本地保存；模型按工具或系统设置推理，允许使用云模型。
- 统一方法论、上下文交接和任务闭环贯穿各 Agent。
- 浅色、深色与系统主题共享当前视觉规范。

原型业务数据目前在页面内存中，刷新会恢复示例；仅主题偏好持久化。工具执行、发布与规则验证均为演示，不能当作真实执行证据。桌面壳、持久化方案、Agent 协议与发布平台尚未选型。
