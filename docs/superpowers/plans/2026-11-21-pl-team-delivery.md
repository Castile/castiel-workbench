# 团队管理与项目交付实施计划

**目标**　把已确认的成员成长和项目交付设计接入本地桌面工作台。执行采用 superpowers:subagent-driven-development，按模块实现与验证。

**架构**　沿用 React、Electron 和现有文档存储。成员、项目、任务共用既有 ID。外部接口仅显式读取，源系统负责人独立于本机排期。设计见 [需求与验收标准](../specs/2026-11-21-pl-team-delivery-design.md)。

## 实施与验收

- [ ] 成员与关键事件。在 prototype/src/pl/People.jsx 实现可检索名册、本机头像、归档转交、红黑事迹、私有纪要、感谢稿和可导出的本地 PNG。核验红事件导出字段白名单、黑事件跟进及历史回查。
- [ ] 辅导与绩效。在 prototype/src/pl/Performance.jsx 实现多周期目标、阶段确认历史、1:1、今日到期事项和年度自评。验证同一证据去重、草稿持久和未完成跟进。
- [ ] 项目与数据源。在 prototype/src/pl/Delivery.jsx 实现本地项目与工作项、CSV/JSON、字段/人员/状态映射、重复导入及排期。校验工单甲、排期乙的 8h 只计入乙；断网保留成功结果。
- [ ] 主进程与集成。在 prototype/desktop 添加具名只读系统接入和仅文本润色，限制请求范围；在 WorkspaceViews 接入成员、项目、设置和今日，各模块共享 App 现有任务/人员。旧文档缺省新增集合，备份恢复覆盖新记录。
- [ ] 跑 npm run check、桌面本地存储及模拟服务用例；通过运行界面检查主题、窄窗、表单、海报和导入。分别说明本机验证、模型及内网联调情况，提交源码与文档。

## 重点回归

旧成员无头像；重名和被归档人员；超过文档体积的图片；重新同步更改远端负责人时保留本地指派；取消或失败的 AI 润色保留草稿。
