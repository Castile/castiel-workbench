# 对话体验优化

2026-10-26。按用户已授权的持续设计与开发方式，直接在现有 React/Electron 界面实施，不重新搭建项目。

## 目标与取舍

参考 Codex 的专注阅读列、靠右用户提问、开放式 Agent 回复与底部输入区。保留原有导航、会话、模型/工具/空间选择和深浅主题。独立聊天默认收起任务上下文，仍可按需打开；任务执行的成果/记录入口保留。界面参考只指导布局，不照搬 Codex 的品牌或添加项目菜单。

Markdown 使用 react-markdown、remark-gfm 与 rehype-highlight：支持标题、列表、引用、任务清单、表格、行内代码与围栏代码。代码显示语言、横向滚动和原文复制；未知语言与未闭合流式代码保持可读。禁止原始 HTML 与远程图片自动加载，链接经明确点击后才打开。

补充问题采用对话内卡片：有描述的单选项、自行填写、可选说明、多题进度与返回修改、显式提交、空答校验、提交中禁用与失败保留输入。敏感问题使用密码输入，不默认选中推荐项。命令/文件授权显示原命令和目录，仍只允许本次或拒绝。同一轮多个工具请求排队展示，不能被后到请求覆盖。

Codex、Claude、Gemini 使用官方来源的本地图标；未知工具使用通用图标。保留来源说明，品牌资产不代表合作或官方出品。

## 实施顺序

1. 保存当前对话截图与官方参考，核实资源来源。
2. 新增 Markdown、消息列表、复制按钮、图标、交互请求组件，接入原页面与实际运行状态。流式更新只在接近底部时跟随，阅读历史时保留位置，提供回到最新按钮。
3. 调整聊天布局、输入框、自适应与主题；保持原业务、独立设置和本地数据协议。
4. 为安全渲染和真实请求排队/提交增加必要回归检查；在浏览器中验证 Markdown、代码复制、多题、自由输入、失败重试、授权、窄屏和深浅色。
5. 运行全量检查并重新打包。当前运行的旧包必须先正常退出，保存用户已有会话；不覆盖运行中的应用资源。记录证据与未验证范围后提交本地 Git。

## 完成标准

用户/Agent 的视觉角色清晰；长代码和宽表格不撑破窗口；空答不能提交、输入失败不丢失、多项请求均可处理；新样式实际渲染和主题/窄屏交互经过检查。界面夹具与离线检查不等于真实供应商调用。本次无需再次发送计费的推理请求。
